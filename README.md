# Алина — AI-консультант для ВКонтакте

[![Python](https://img.shields.io/badge/python-3.10%2B-blue)](https://www.python.org/downloads/)
[![vk-api](https://img.shields.io/badge/vk--api-11.9%2B-green)](https://pypi.org/project/vk-api/)
[![openai](https://img.shields.io/badge/openai--sdk-1.30%2B-orange)](https://pypi.org/project/openai/)
[![License: MIT](https://img.shields.io/badge/license-MIT-yellow.svg)](LICENSE)

**Алина** — полностью автоматизированный чат-бот для сообщества ВКонтакте, который
отвечает пользователям от имени онлайн-университета **Zerocoder** (zerocoder.ru):
консультирует по программам и курсам, помогает выбрать направление обучения и
аккуратно собирает контакты для отдела продаж.

Бот построен на **LongPoll-API ВКонтакте** и **OpenAI-совместимом сервисе ProxyAPI**:
не требуется собственного сервера с публичным адресом — достаточно процесса,
слушающего события сообщества.

---

## Возможности

- 🤖 **Живой диалог с ИИ** — модель `gpt-4o-mini` (или любая другая через ProxyAPI) отвечает в фирменном стиле Алины.
- 🧠 **База знаний о курсах** — все программы, тарифы и контакты Zerocoder зашиты в промпт; модель не «выдумывает», а отвечает только по актуальным данным.
- 💬 **Контекст диалога** — бот помнит последние 20 реплик каждого пользователя (скользящее окно), корректно ведёт многошаговые беседы.
- 🔄 **Команда сброса** — `/start`, `/clear`, `/начать` очищают историю и начинают диалог заново.
- 📋 **Мягкий лид-кэпчур** — в конце ответа предлагает оставить заявку менеджеру через форму на сайте.
- 🛡 **Отказоустойчивость** — ошибки API изолированы: процесс не падает, пользователь получает вежливый ответ, ошибки пишутся в лог.
- 🔐 **Секреты под замком** — все ключи только в `.env`, который исключён из Git; в репозиторий попадает лишь шаблон `.env.example`.

| Слой | Технология |
|------|------------|

## Как это работает

```
Пользователь --> сообщение в сообщество ВК
      |
      v
bot.py (LongPoll-петля): получает событие MESSAGE_NEW
      |
      v
DialogStore: сохраняет реплику в историю диалога (peer_id)
      |
      v
ProxyChatClient: chat.completions (SYSTEM_PROMPT + история)
      |
      v
Ответ модели + FORM_OFFER --> vk.messages.send --> пользователь
```

Подробнее — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Быстрый старт

### 1. Ключ доступа сообщества ВКонтакте

1. «Управление» → «Настройки» → «Работа с API».
2. Создайте ключ доступа сообщества с правами: **Сообщения (messages)**, желательно **Управление сообществом (groups)**.
3. Включите «Сообщения сообщества» и «Возможности ботов» (Настройки → Сообщения).
4. Запишите числовой **ID сообщества** (без минуса).

### 2. Ключ API

Зарегистрируйтесь на **proxyapi.ru**, создайте ключ в разделе «Ключи API» (показывается один раз) и пополните баланс.

### 3. Конфигурация

```bash
copy .env.example .env    # Windows
# cp .env.example .env    # Linux/macOS
```

Заполните `VK_TOKEN`, `VK_GROUP_ID`, `PROXY_API_KEY` (см. таблицу ниже).

### 4. Установка и запуск

```bash
# вариант 1 — pip-упаковка (рекомендуется)
pip install -e .
zerocoder-bot

# вариант 2 — напрямую из репозитория
pip install -r requirements.txt
python -m zerocoder_vk_bot.bot
```

Бот крутит LongPoll-петлю и отвечает в реальном времени. Для круглосуточной работы
разверните его на VPS (`systemd`, `pm2`) или в Docker-контейнере.

## Переменные окружения

| Переменная | Обязательная | По умолчанию | Описание |
|------------|:---:|-----|----------|
| `VK_TOKEN` | ✅ | — | Токен доступа сообщества ВКонтакте |
| `VK_GROUP_ID` | ✅ | — | Числовой ID сообщества ВКонтакте |
| `PROXY_API_KEY` | ✅ | — | Ключ API ProxyAPI |
| `PROXY_API_BASE_URL` | — | `https://api.proxyapi.ru/openai/v1` | Базовый адрес API |
| `PROXY_API_MODEL` | — | `gpt-4o-mini` | Модель для генерации ответов |
| `PROXY_MAX_TOKENS` | — | `300` | Лимит токенов на ответ |
| `PROXY_TIMEOUT` | — | `60` | Таймаут запроса, сек |
| `HISTORY_LIMIT` | — | `20` | Какую длину истории диалога помнить |

Если обязательные переменные не заполнены, бот выведет список недостающих и остановится — никаких «молчаливых» ошибок.

## Модель ветвления (git flow)

Проект ведётся по упрощённому Git Flow: стабильный `main`, интеграционный `develop`,
временные `feature/*`-ветки для новых возможностей.

```
main          o----o----o (v1.0.0)
             /      /
develop     o------o--------o
                /
feature/...  o-
```

- `main` — стабильная версия, тег `v1.0.0`; только проверенный код.
- `develop` — интеграционная ветка разработки.
- `feature/*` — отдельная ветка на каждую задачу (пример: история диалога, база знаний).

## Безопасность

- Секреты только в `.env`, который есть в `.gitignore` — в Git и на GitHub попадает лишь `.env.example` с плейсхолдерами.
- Токены не логируются; ошибки API пишутся в лог без секретов.
- Не переименовывайте `.env.example` в `.env.example.bak` и не коммитьте реальные ключи — после публикации их придётся отзывать.
