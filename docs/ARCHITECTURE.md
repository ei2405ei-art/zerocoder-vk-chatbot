# Архитектура бота

## Общая схема

```
┌──────────┐   сообщение    ┌────────────────────────────┐
│  ВКонтакте │ ───────────> │          bot.py            │
│ (сообщество)│ <─────────── │  LongPoll-петля (слушатель) │
└──────────┘    ответ      └────────────┬───────────────┘
                                        │
                     1. складывает текст в DialogStore (история диалога)
                     2. вызывает ProxyChatClient.get_reply(messages)
                                        │
                    ┌───────────────────▼────────────────────┐
                    │          proxy_client.py               │
                    │  OpenAI-совместимый HTTP-клиент         │
                    │  (base_url = api.proxyapi.ru/openai/v1) │
                    └───────────────────┬────────────────────┘
                                        │ POST /chat/completions
                    ┌───────────────────▼────────────────────┐
                    │             Чат-модель                 │
                    │  SYSTEM_PROMPT (Алина) + история       │
                    └────────────────────────────────────────┘
```

## Модули

| Модуль | Ответственность |
|--------|-----------------|
| `bot.py` | Точка входа. Подписка на события `VkBotLongPoll`, обработка `MESSAGE_NEW`, команды сброса диалога, отправка ответов через `vk.messages.send`. |
| `config.py` | Загрузка `.env` через `python-dotenv`, валидация обязательных переменных, приведение типов. При отсутствии секретов останавливает запуск с понятной ошибкой. |
| `proxy_client.py` | Тонкая обёртка над официальным SDK `openai`: изолирует конкретный API-провайдер, чтобы бот не зависел от вендора напрямую. |
| `system_prompt.py` | Системный промпт Алины + текстовый блок `FORM_OFFER`, который добавляется в конце каждого ответа. |
| `knowledge_base.py` | Структурированная база знаний об университете Zerocoder (программы, тарифы, контакты). Встраивается в системный промпт. |

## Ключевые решения

**1. История диалога (`DialogStore`)**
- `deque` с максимальной длиной (по умолчанию 20 сообщений) — «скользящее окно»: сохраняются только последние N реплик, билд запроса не растёт бесконечно.
- Ключ — `peer_id`: у каждого пользователя своя независимая ветка диалога на всё время работы процесса.
- Команды `/start`, `/clear`, `/начать`, `начать заново` полностью очищают историю.

**2. Промпт как код (`system_prompt.py`)**
- Промпт собирается из строковой константы + базы знаний — правки не требуют пересборки, а модель всегда получает актуальные данные.
- Правила безопасности: «не выдумывай», «не уходи от темы», «не продавай агрессивно» — зашиты в инструкции модели.

**3. Мягкий лид-кэпчур (`FORM_OFFER`)**
- В конце каждого ответа бот деликатно предлагает оставить заявку менеджеру — конверсия в заявки без навязчивости.

**4. Graceful degradation**
- Ошибки API не падают процесс: перехватываются в цикле, пользователю отправляется вежливое сообщение, а стек ошибки пишется в лог.
- Ошибки отправки сообщений тоже изолированы (`send_message` оборачивается в try/except).

**5. Конфигурация через окружение**
- Все настройки — переменные окружения из `.env`; секреты никогда не попадают в код и в Git (см. `.gitignore`).

## Потенциальные улучшения

- **Персистентность истории**: сейчас история хранится в памяти и теряется при рестарте. Замена `DialogStore` на Redis/SQLite сохранит контекст между перезапусками и на нескольких инстансах.
- **Rate limiting и цена**: лимит по пользователям в минуту, счётчик токенов.
- **Очередь/вебхук**: замена LongPoll на Callback API уберёт необходимость постоянно открытого соединения.
- **Тесты**: юнит-тесты на `DialogStore` и `ProxyChatClient` (с mock), интеграционный сценарий.
- **Мультипровайдерность**: абстракция поверх `ProxyChatClient` для переключения между ProxyAPI, GigaChat и другими OpenAI-совместимыми эндпоинтами.
